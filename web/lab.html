Experiment boundaries

  • One investigation at a time
  • Network disabled inside every experiment
  • 2 CPU cores · 2 GB memory per container
  • Read-only host source mount
  • Tests and dependencies cannot be edited by the model
  • Three measured benchmark samples per candidate

Workspace

To investigate another Go module, initialize it and launch Veda for that workspace.

bin/veda init --workspace /path/to/repo
bin/veda serve --workspace /path/to/repo

V0 handles small Go modules, with standard-library or vendored dependencies.
